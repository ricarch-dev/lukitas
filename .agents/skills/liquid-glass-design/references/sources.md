# Research evidence and freshness

Reviewed on 2026-11-16. These are research notes, not vendored upstream instructions. Re-read official documentation for the installed versions before implementation. If the manifest, lockfile, native build, declarations, and docs disagree, stop the affected API choice and report the mismatch; do not silently upgrade dependencies.

## Official sources consulted

| Source                                                                                                                      | Verified guidance                                                                                                                                                                                                     |
| --------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Apple HIG: Materials](https://developer.apple.com/design/human-interface-guidelines/materials)                             | Liquid Glass separates navigation/controls from content; use sparingly; regular versus clear; accessibility changes material appearance.                                                                              |
| [Apple HIG structured content](https://developer.apple.com/tutorials/data/design/human-interface-guidelines/materials.json) | Readable first-party representation used because the ordinary HIG page did not return article text.                                                                                                                   |
| [Expo SDK 58: GlassEffect](https://docs.expo.dev/versions/v58.0.0/sdk/glass-effect/)                                        | Native glass availability, `GlassView`, `GlassContainer`, capability checks, accessibility caveat, opacity guidance, and ordinary-View fallback. Docs recommend package `~58.0.5`; not an installed dependency claim. |
| [Expo SDK 58: BlurView](https://docs.expo.dev/versions/v58.0.0/sdk/blur-view/)                                              | Android target/reference setup, blur methods, SDK 31 performance distinction, list rendering order, clipping. Docs recommend `~58.0.6`; blur is not Liquid Glass.                                                     |
| [Expo Router: Native tabs](https://docs.expo.dev/router/advanced/native-tabs/)                                              | SDK 58 stable import, system material, adaptive foreground colors, Android/iOS safe-area differences, keyboard and tab-state caveats. This guide is rolling; recheck against installed Router declarations.           |
| [Expo tagged SDK evidence](https://github.com/expo/expo/tree/expo%4058.0.22)                                                | Context7 retrieved SDK 58.0.22 GlassEffect README and native-tabs documentation; corroborating same-major evidence, not exact patch 58.0.23 verification.                                                             |
| [React Native 0.88: AccessibilityInfo](https://reactnative.dev/docs/0.88/accessibilityinfo)                                 | Platform-specific transparency/contrast queries, reduced-motion state, preference change subscriptions.                                                                                                               |
| [Android mobile color guidance](https://developer.android.com/design/ui/mobile/guides/styles/color)                         | Semantic tokens, foreground/surface pairs, stable brand meanings, light/dark surfaces, non-color indicators.                                                                                                          |
| [Android app accessibility](https://developer.android.com/guide/topics/ui/accessibility/apps)                               | 48dp touch areas, 4.5:1 ordinary-text and 3:1 large-text contrast, meaningful labels and roles.                                                                                                                       |

The 3:1 essential non-text contrast check in the project checklist follows [WCAG 2.2, 1.4.11](https://www.w3.org/TR/WCAG22/#non-text-contrast); verify the criterion when auditing rather than treating native screenshots as a conformance certificate.
